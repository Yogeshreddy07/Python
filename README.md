## What's in here

This repo tracks everything I've learned and practiced while getting comfortable with Python. Organized into two tracks:

- **Python Basics** — exercises, notes, and practice problems from structured courses
- **Python DSA** — Jupyter notebooks covering Python through the lens of data structures and algorithms
